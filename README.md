# Postie Data Science Case Study

This repository contains a data science case study prepared for a Postie interview presentation. The project includes exploratory data analysis, modeling, evaluation, and a summary of key findings and recommendations.

## Project Goal

To be updated once the project prompt and data are finalized.

## Repository Structure

- `notebooks/`: exploratory analysis, modeling, and final results summary
- `src/`: reusable Python helper functions
- `data/`: local data files, not committed to the repository
- `outputs/`: generated figures and tables
- `presentation/`: final presentation materials

This project uses conda.

conda env create -f environment.yml
conda activate postie
